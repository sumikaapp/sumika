## ダウンロード

[Releases ページ](../../releases/latest) から環境に合わせて選んでください。

| ファイル | 形式 | 対象 |
|---------|------|------|
| `smart_speaker_*_cpu_x64-setup.exe` | インストーラー（推奨） | すべての Windows PC |
| `smart_speaker_*_cuda_x64-setup.exe` | インストーラー | NVIDIA GPU 搭載 PC（聞き取りが高速）。**別途 CUDA Toolkit 12.8 以降が必要** |
| `smart_speaker-*-windows-cpu_portable.7z` | ポータブル版 | インストールせずに使いたい方 |
| `smart_speaker-*-windows-cuda_portable.7z` | ポータブル版 | 同上（NVIDIA GPU 向け）。**別途 CUDA Toolkit 12.8 以降が必要** |

`latest-cpu.json` / `latest-cuda.json` はアプリの自動更新用ファイルです（手動ダウンロード不要）。

### 初回だけ「Windows によって PC が保護されました」と表示されます

有償のコード署名証明書を使っていないため、ダウンロードした実行ファイルを開くと
Windows SmartScreen の警告画面が出ます（インストーラー版・ポータブル版とも）。
次の 2 手順で実行できます。

1. 青い画面の「**詳細情報**」をクリック
2. 下に現れる「**実行**」をクリック

心配な場合は、ダウンロードしたファイルを [VirusTotal](https://www.virustotal.com/gui/home/upload)
にかけてから実行してください。

## はじめに読んでください — 必要なもの

このアプリは**「AI の頭脳」と「声」を別のソフトから借りて動きます**。
アプリ本体は数十 MB ですが、初回セットアップでそれらを取得するため
**合計で 15 GB 前後のダウンロードと空き容量**が必要です。回線と時間に余裕のあるときにどうぞ。

| 必要なもの | 容量の目安 | 入手方法 |
|---|---|---|
| [Ollama](https://ollama.com/) + 応答生成モデル（gemma4） | 約 9.6 GB | セットアップが自動で導入 |
| Whisper 音声認識モデル | 約 1.6 GB | 初回起動時に自動ダウンロード（軽いモデルにも変更可） |
| [VOICEVOX](https://voicevox.hiroshiba.jp/) | 1〜3 GB | 公式サイトから手動インストール |

### 動作環境

| 項目 | 最小 | 推奨 |
|---|---|---|
| OS | Windows 10 / 11（64bit） | Windows 11 |
| メモリ | 8 GB | 16 GB 以上 |
| 空き容量 | 15 GB | 20 GB 以上 |
| マイク・スピーカー | 必須 | ノイズキャンセリング付きマイク |
| GPU（CUDA 版のみ） | NVIDIA GTX 1060 以上 + ドライバー 570.x 以上 | RTX 3060 以上 |
| CUDA Toolkit（CUDA 版のみ） | **12.8 以降の 12.x が必須**。入っていないと起動しません | 12.8 |

CPU 版は GPU なしで動きます。**迷ったら CPU 版**を選んでください。

> **CUDA 版を選ぶ前に**: CUDA 版は `cudart64_12.dll` / `cublas64_12.dll` を必要としますが、
> これらは NVIDIA のグラフィックスドライバーには含まれていません。
> [CUDA Toolkit Archive](https://developer.nvidia.com/cuda-toolkit-archive) から **12.8 以降の 12.x**
> を別途インストールしてください（配布ビルドは CUDA 12.8 で作っています。13.x は不可）。
> 入れずに起動すると、アプリの画面が出る前に
> 「`cudart64_12.dll` が見つからないため、コードの実行を続行できません。」
> 「`cublas64_12.dll` が見つからないため、コードの実行を続行できません。」
> のダイアログが順に出ます。
> どちらも**アプリを再インストールしても直りません**（ダイアログはそう案内しますが、
> 足りないのはアプリのファイルではなく CUDA Toolkit の側です）。

## 使いはじめるまで

1. **インストール**
   - インストーラー版: ウィザードに従い、スタートメニューから起動
   - ポータブル版: 7z を任意の場所（ユーザーフォルダ配下を推奨）に展開 →
     `setup.bat` を実行（Ollama を自動導入）→ `START-Smart-Speaker.vbs` で起動

2. **[VOICEVOX](https://voicevox.hiroshiba.jp/) をインストール**
   - **ポータブル版**: 起動しておく必要はありません。`START-Smart-Speaker.vbs` が
     アプリより先に VOICEVOX を立ち上げます（画面には出ません）。
   - **インストーラー版**: **VOICEVOX を起動してからアプリを開いてください。**
     先に開いてしまっても、VOICEVOX を起動して画面の「もう一度試す」を押せば
     そのまま使えます。

3. **呼びかける声を登録する（初回のみ・1 分）**
   呼びかけの検出モデルは**あなたの声から作ります**。配布版には同梱していません
   （他人の声のデータを配らないための設計です）。
   初回起動時に案内が出るので、マイクに向かって同じ言葉を 3 回録音してください。
   家族それぞれの声を最大 3 人まで登録できます。

4. **呼びかける**
   登録した言葉（例:「ねえ、さくら」）で話しかけると応答します。

> 手順 1〜2 が終わっていないと、アプリが理由と次の手順を画面に表示します。
> 足りないものを入れれば、**再起動せずにそのまま**使えるようになります。

## できること

呼びかけたあと、ふつうの日本語で頼めます。

| | 例 |
|---|---|
| 天気・予定 | 「今日の天気は？」「明日の予定教えて」 |
| 買い物メモ・家族の伝言 | 「牛乳を買い物リストに入れて」「お母さんに帰りが遅くなるって伝えて」 |
| 家計簿 | 「スーパーで 3200 円使った」「今月あといくら使える？」 |
| 料理 | 「肉じゃがのレシピ教えて」→ 手順を 1 ステップずつ読み上げ・「次」で進む |
| タイマー | 「3 分はかって」 |
| 音楽 | 「音楽かけて」「次の曲」「もう少し小さく」 |
| 宿題モード | 子ども向けの出題と答え合わせ |
| 調べもの | Web 検索と、`data/knowledge/` に置いたご家庭の資料からの検索 |
| 設定変更 | 「もう少しゆっくり話して」など、声で設定を変えられます |
| 家電操作 | スマートホーム機器の操作（別途セットアップが必要） |

## プライバシー

- 音声とテキストは**外部に送信しません**。すべて PC 内で処理します
- 利用状況の収集（テレメトリ）はありません
- 外部通信が発生するのは、天気・カレンダー購読の更新・Web 検索など、
  **あなたがその機能を使ったときだけ**です
- 呼びかけ検出用の声のデータは `models/` にローカル保存され、どこにも送られません

## 困ったときは

| 症状 | 対処 |
|------|------|
| 呼びかけても反応しない | 「声の登録」が済んでいるか確認（設定 →「きこえ方」）。登録済みなら、登録時と同じ言い方・距離で試してください |
| 応答が返ってこない | Ollama が動いているか確認（コマンドプロンプトで `ollama serve`） |
| 声が出ない | VOICEVOX が起動しているか確認（http://localhost:50021 が開けるか） |
| 聞き取りが遅い | 設定から軽い Whisper モデル（small / base）に変更、または CUDA 版を使用 |
| CUDA 版が起動せず `cudart64_12.dll が見つからない` と出る | CUDA Toolkit 12.8 以降の 12.x が入っていません（ドライバーだけでは足りません）。入れて再起動するか、CPU 版を使用 |

解決しない場合は [Issues](../../issues) へ、症状と使用バージョンを添えてお知らせください。
